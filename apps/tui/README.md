# `@min-agent/tui`

Ink terminal UI for min. Drives `@min-agent/client` (same experience contract as CLI / Web).

Basic chrome uses [`@inkjs/ui`](https://github.com/vadimdemedes/ink-ui) (`Spinner`, `Badge`, `Alert`, `ProgressBar`, `ConfirmInput`) via `src/ui/`, themed through `ThemeProvider` + `extendTheme`. The composer and transcript paint stay custom — they need multiline editing and IME caret sync that stock `TextInput` does not cover. Slash suggestions and `/resume` session picks use plain Ink Text lists; permission prompts use `ConfirmInput` (with host-handled `a` for remember-session).

The transcript scrolls (PageUp / PageDown) and wraps instead of clipping to a short window. `--session` restores the saved history. Lines typed while the agent is running stay in the composer; Enter queues them. `/resume`, `/new`, `/reset`, and `/compact` wait until the run is idle. `/resume` with no id opens an ↑↓ list to switch sessions. Each row shows the first prompt, the latest prompt when it moved on, the turn count, the local time, and a short id. `/resume <id>` switches immediately; a unique prefix of the id is enough, and an unknown id does not create a session. The composer edits by grapheme (Alt+Enter or Ctrl+J for a newline). A permission prompt shows the tool or the root grant; no answer denies it after two minutes.

User and assistant turns use a left bar and accent foregrounds with no `you` / `min` labels and no block background fills. The default theme follows Catppuccin Mocha (green user / blue assistant accents on the terminal background). The composer uses the brand mint (same as the MIN banner) for its top/bottom rules. The body is always at least two terminal rows (2× line height), soft-wraps long lines, grows with Shift+Enter / Alt+Enter / Ctrl+J newlines, and reassembles split key sequences so Shift+Enter is not lost. Tool calls use a `▸` marker; tool output is collapsed to one summary line by default and expands with Ctrl+O. Session chrome (`sys` / `note` / `err`) stays muted. Type `/` and the command list opens above the composer, so the input stays on the same row. Tab or ↑↓ completes a command. The `/resume` list uses that same slot. Assistant text is a small Markdown document (headings, emphasis, inline code, fenced code, lists, quotes, links). A closed `mermaid` fence is drawn as a diagram. Each transcript row is one screen line, and the lines above the window stay reachable with PageUp / PageDown. While a run is in progress the line under the transcript spins differently for thinking, writing, a tool call, a follow-up, and an approval wait, and the status words rotate (pondering, composing, running bash, …). When the model streams a reasoning summary it shows as dim `think` lines (not stored in the session). Spinner paints pause while the terminal tab is unfocused so background tabs do not flicker. The bottom status bar shows the working directory (plus git branch when available) and the active model with thinking intensity and context usage percent. A dim `/context` breakdown of system / conversation / skills / mcp / tools shares is available on demand.

Colors, frame markers, and spinner hues come from `src/theme.ts`, fed by `@min-agent/config`. Put `ui.theme` and `ui.themeOverrides` in `~/.min/config.json` or `~/.min/projects/{project}/config.json`. Chord overrides go in `~/.min/keybindings.json` (or `ui.keybindings` in a preference file) and merge onto the built-in table; unknown command names are ignored. `MIN_THEME` and `--theme` win. `settings.permissions.bash: "allow"` turns bash on, and `settings.permissions.write: "ask"` confirms writes. Permission grants stay in `.min/permissions.json`. The file list, layer order, and command ids are in [`packages/config/README.md`](../../packages/config/README.md).

Markdown parsing lives in `@min-agent/render` (`markdown-it` → `RenderBlock`). This app re-exports it from `src/render.ts` and paints in `paint.ts`.

```bash
pnpm min-tui
pnpm min-tui -- --provider mock
```
